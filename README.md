# Veerisetty Guru Charan Teja | AI/ML Engineer Portfolio

A single-page personal portfolio website with a red and black cyber-modern theme. It showcases my skills, my **Insurance Prediction Project**, other projects, education and contact details.

## Sections

- **Hero**: name, role and quick links
- **About**: short professional bio and key facts
- **Skills**: languages, web and database tools, AI/ML and engineering skills
- **Featured Project**: Insurance Prediction Project
- **Other Projects**: E-commerce Website and Job Portal Backend
- **Education**: B.Tech at Uttaranchal University, Dehradun
- **Contact**: email and GitHub

## Featured Project: Insurance Prediction Project

A machine learning app that predicts a person's health insurance cost from the details they enter, using a Random Forest model.

Repository: https://github.com/charanpandu18/Insurance-Prediction.Ml-App.git

## Tech Used

- HTML, CSS and a small amount of JavaScript (no frameworks or build step)
- Google Fonts: Orbitron, Inter and JetBrains Mono

## Run Locally

1. Download or clone this folder.
2. Open `index.html` in any modern browser.

No installation is needed. An internet connection is needed only to load the fonts. Without it, the page uses system fonts.

## Deploy

Because this is a static site, you can host it free on:

- **GitHub Pages**: push the folder to a repository, then go to Settings, Pages, and select the main branch.
- **Netlify** or **Vercel**: drag and drop the folder or connect the repository.

## Customize

All content lives in `index.html`.

- Colors and fonts: edit the variables at the top of the `<style>` block (`--red`, `--bg`, `--font-display` and so on).
- Text: edit the section content directly in the HTML.
- Links: update the GitHub project links in the Featured Project and Other Projects sections.
